# dmtf.ovh

Official source code of my personal website: **dmtf.ovh**.

This repository contains the website's frontend, components, configuration, and other project files used to build and maintain the site.

## Features

- Modern web application
- Responsive layout
- Clean and modular project structure
- Easy to maintain and extend

## Project Structure

```
.
├── app/           # Application pages
├── components/    # Reusable UI components
├── public/        # Static assets
├── styles/        # Global styles
└── ...
````

## Development

Clone the repository:

```bash
git clone https://github.com/DAMIOTF/dmtf.ovh.git
````

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```
